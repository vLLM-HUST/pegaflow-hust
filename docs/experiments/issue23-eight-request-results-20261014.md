# 八请求批次实验：停止时结果记录

实验按用户指令停止。统计纳入 28 个完整配对 cohort，每组 224 条、四组共 896 次前景执行，均成功；另有第 29 个 cohort 的四组共 32 次成功执行，停止时最后一组固定观察窗尚未结束，因此单列保留。合计保存 928 次成功前景执行。原定每组 1024 条的运行预算尚未完成。

81、91 每节点两张 NPU；Qwen3.5-35B-A3B、BF16、TP=2、默认 OS 调度。输入 4097 token，完整混合缓存复用 4096 token，前景输出 1 token。每批八条缓存，每条 148,275,200 字节，共 1,186,201,600 字节。共享 RDMA 软件注入预算为 1 Gb/s；平滑间隔 1.2 秒，集中偏移 4.2 秒，四组平均释放偏移一致。每组独立观察窗至少 35 秒，并设置四条已有 decoder；源准备与 arm 切换单独进行，模型/engine 在整个条件内持续运行。

## 完整配对结果

| 组别 | TTFT均值（秒） | TTFT p95（秒） | TTFT p99（秒） | 提交至完整完成 p99（秒） | 背景SSE间隔 p99（毫秒） |
|---|---:|---:|---:|---:|---:|
| RDMA集中 | 16.774 | 20.692 | 22.228 | 9.482 | 456.3 |
| RDMA平滑 | 11.209 | 15.659 | 17.303 | 1.216 | 479.1 |
| 本地拷贝集中 | 12.847 | 15.337 | 16.782 | 0.089 | 455.1 |
| 本地拷贝平滑 | 10.070 | 14.452 | 15.150 | 0.028 | 470.9 |

RDMA 平滑的 TTFT 均值较集中下降 33.2%，配对 cohort 均值差为 -5.566 秒；提交至完整完成 p99 从 9.482 秒降至 1.216 秒。该完成指标包含共享软件额度的排队。减去各请求等齐 cohort 的等待后，RDMA TTFT 均值为 15.311→9.780 秒，结果方向一致。

本地拷贝 TTFT 均值也下降 2.777 秒，表明端到端差异还包含非网络阶段的贡献；模型批处理与下游恢复时序是待进一步区分的因素。RDMA 与本地的配对均值效应之差约为 -2.788 秒，是本轮描述性对照；不能把全部 TTFT 改善都归因于物理网络拥塞。背景 SSE 间隔均值及 p99 没有体现一致改善，因此本轮支持传输排队和新请求 TTFT 的机制观察，尚不能得出已有 decoder TPOT 改善的结论。

p99 为 224 条请求/组的经验分位数，请求和 token 间隔存在批次及时间相关性。原定八个时间 block 当前只完成一个完整 block及十二个后续 cohort；报告不提供计划中的 block bootstrap 置信区间。本轮结果是停止时的阶段性证据。

## 验收与材料

896 条配对前景全部出现完整 eligible/posted/completed，载荷正确，客户端 usage 均为输入 4097、输出 1。两 TP rank 共 1792 条首个 D 端 model-work 记录全部为 computed_tokens=4096、scheduled_tokens=1，表明实际使用完整 checkpoint，只计算最后一个 prompt token。

1 ms 的集中提交跨度标记在 RDMA 的 2/28 批次、本地拷贝的 25/28 批次超限。所有记录均保留，统计采用实际执行结果；最大跨度分别约 5.24、2.02 ms。结果不能视为所有集中提交都精确同步。

软件注入预算缩放共享服务能力，真实 RDMA 读取仍通过原速物理链路；当前证据不直接刻画交换机队列或 ECN/PFC。额外 host-only RDMA 竞争流量条件尚未运行。

前期资格运行存在共享文件可见性导致的在线 trace 缺失判定；原生记录和传输均成功。随后改为从 D 端读取完整 JSONL 行并保存独立副本，本轮主运行使用该修复。停止产生的 CancelledError 与 KeyboardInterrupt 为主动取消记录，原始日志保留；运行状态另标记 stopped_by_user。
